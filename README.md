## 🔧 What I'm building

### [`quant-finance-portfolio`](https://github.com/himadri027roy/quant-finance-portfolio)

A Python project bridging my physics background and quantitative finance. Every component is benchmarked and documented to research-paper standards.

- **Options Pricing** — Black–Scholes with full Greeks (Δ, Γ, ν, Θ, ρ); Newton–Raphson implied-volatility solver
- **Monte Carlo** — European & Asian options with antithetic variates for variance reduction; convergence analysis verifying $\mathcal{O}(1/\sqrt{N})$
- **Backtesting** — vectorised engine, four trading strategies, realistic transaction-cost modelling
- **Risk Management** — VaR & Expected Shortfall via three methods (historical, parametric, Monte Carlo), validated by the Kupiec POF test
- **Portfolio Optimisation** — Markowitz mean-variance framework, stress-tested across GFC, COVID, and rate-shock scenarios

I'm also an **AI Training Specialist at Turing**, validating model outputs for mathematical correctness and robustness — mirroring the independent validation workflow defined under **SR 11-7** for financial model risk management.
